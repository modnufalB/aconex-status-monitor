Privacy Policy for Aconex Status Monitor

**Effective date:** 12 October 2026

Aconex Status Monitor is a browser extension developed by Eng. Mohammad Nufal to highlight document statuses, calculate a current-page summary, provide optional local status-change notifications, and export the current Aconex register page to CSV.

Data accessed

The extension can read the content displayed in Aconex document-register pages on `aconex.com` domains. Depending on the register columns selected by the user, this content may include document numbers, titles, revisions, versions, statuses, disciplines, creator names, and dates.

How data is used

Data is processed locally in the user's browser only to:

  • apply status highlighting;
  • calculate the popup summary;
  • detect status changes previously observed by the extension;
  • generate a CSV file requested by the user; and
  • display browser notifications requested by the user.

    • Data storage

    The extension may use browser-local extension storage to remember user interface preferences and previously observed status values. This information remains in the user's browser profile unless the user removes the extension or clears extension data.

    Data sharing and transmission

    The extension does not transmit Aconex register data to the developer or to external servers. The extension does not sell, rent, or share user data with third parties. The extension does not load or execute remotely hosted code.

    Permissions

    • Storage: Saves local preferences and previously observed status values.
    • Notifications: Displays locally generated status-change and test notifications.
    • Scripting and Aconex host access: Reads and highlights information on supported Aconex pages and produces summaries and exports.
    • Tabs: Identifies the active Aconex tab and accesses its URL for extension functionality.
    • Downloads: Saves a CSV file when the user selects Export CSV.

    Data retention and deletion

    Locally stored extension data remains until the user clears browser extension data or removes the extension. Exported CSV files are retained according to the user's browser and device download settings.

    Children's privacy

    The extension is intended for workplace document-management use and is not directed to children.

    Changes to this policy

    This policy may be updated when extension functionality or data practices change. The effective date will be revised when material changes are made.
